# Changelog

## 0.1.0

- SQLite and optional PostgreSQL/pgvector temporal fact storage.
- User-scoped revision keys, expiry, atomic batches and physical deletion.
- Hybrid/vector retrieval and an explicitly classical Grover-inspired simulator.
- Bounded deterministic personalized PageRank for up to two related facts.
- Optional schema-checked, source-grounded AI extraction with local key settings.
- Python library, JSON CLI, fictional demo, synthetic benchmark and CI.
